# Copy and messaging

A compact shelf of borrowable messaging shapes for common business moments. Use one when the audience, offer, or source material is known but the message does not have a useful first draft yet. Adapt the language to the actual customer, evidence, voice, channel, and desired action; write directly or ask the model to turn the idea into the format you need.

## Choose a starting point

| Need | Open |
|---|---|
| Explain a launch or useful update | [Announce a useful change](01-announce-a-useful-change.md) |
| Connect a real problem to a clear relief | [Problem to relief](02-problem-to-relief.md) |
| Answer a fit, risk, or trust concern | [Explain an objection](04-explain-an-objection.md) |
| Reach out with a relevant useful reason | [Relevant outreach](05-relevant-outreach.md) |
| Follow up with value after interest | [Helpful follow-up](03-helpful-follow-up.md) |
| Teach a concept or mechanism | [Educational explainer](07-educational-explainer.md) |
| Let a real story or evidence carry the message | [Story or proof-led message](08-story-or-proof-led-message.md) |
| Explore distinct openings for one message | [Headline and opening variants](09-headline-and-opening-variants.md) |

## Use with AURA

These are optional starting points, not copy rules or a required funnel. The model or user can combine them, use another angle, or write from an existing plan. When deeper marketing judgment helps, see AURA's [messaging strategy workflow](../../../systems/marketing-synthesis/workflows/strategy/messaging/CONTEXT.md), [hook guidance](../../../systems/content-synthesis/workflows/strategy/hook/CONTEXT.md), [desired-action guidance](../../../systems/content-synthesis/workflows/strategy/desired-action/CONTEXT.md), and [fact-check QA](../../../systems/content-synthesis/workflows/qa/fact-check/CONTEXT.md).

Use verified product, offer, customer, and outcome information. Keep the illustrative examples illustrative; do not turn a sample promise, urgency cue, testimonial, metric, or objection into an organization fact.
