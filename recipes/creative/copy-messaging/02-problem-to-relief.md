# Problem to relief

Use this when the audience already feels a real problem and the offer can show a credible way to make that situation better.

## The idea

Name the observable friction in the customer's language, make the consequence clear without inflating it, then connect the relief to the mechanism that produces it. The message should make the offer feel like a useful response, not a dramatic claim searching for a problem.

## Borrowable shape

**Recognizable problem → consequence or cost of leaving it unresolved → mechanism → improved state → proportionate next step.**

Use the actual problem, audience, and evidence. Let the contrast come from the buyer's lived situation and the offer's real difference. If the result depends on conditions, say what those conditions are; do not promise a universal outcome.

## Tiny illustrative example

**When a travel bag has to be unpacked to find every small item, the trip starts with a search.**

A separated interior keeps the essentials visible and easy to reach, so the traveler can move from packing to use without the same rummaging. **See the interior layout.** Use the actual product construction and supported benefit in the finished message.

## Adapt

Use a sharper pain angle when the audience is already searching for relief; use a calmer explanation when the problem is unfamiliar or trust is fragile. Pair the promise with a concrete mechanism, demonstration, or supported proof when the reader needs to believe it. A comparison, story, or image can carry the same sequence when prose is not the best format.
