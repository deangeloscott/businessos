* **Visual job:** The Specimen
* **Illustrative examples:** Espresso machine + tamper + precision baskets + milk pitcher, pizza oven + peel + cover + thermometer.

## The idea

Make the out-of-the-box system immediately understandable. Arrange the main product with the accessories that are actually included so the viewer can see what arrives, what connects, and what they can use first. A geometric catalog layout is one execution; adapt the arrangement to the product, package, and buyer’s first-use question.

## Borrowable execution

- **What to make felt:** Clear out-of-the-box readiness: *"I can see what is included and what I need to get started."*
- **One visual treatment:** Lens: 40mm Prime. Aperture: f/11 for complete depth of field across all accessories. Lighting: Clean, high-end commercial catalog lighting.
- **Check:** Every accessory displayed must be explicitly included in the base package (no optional add-ons shown as standard).
