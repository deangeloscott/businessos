# Scale 02 — Archetype 14: The Multi-Item Merchandising Routine & Bundle Matrix

* **Visual job:** The Specimen
* **Good for:** showing a complete kit, daily preparation, or complementary product set as one easy choice.
* **Fits:** coffee kits, oil-and-vinegar pairs, pantry trios, and tool kits.

## The idea

Arrange the supplied items so the buyer can understand what belongs together and, when relevant, what happens first. A shared stage, rhythm, or use context turns a collection into a clear merchandising story.

## Borrow this treatment

Use two or three complementary items on a simple pedestal, counter, or work surface. Consistent spacing and light give the set order; a small usage cue can show sequence without covering labels. Preserve relative scale so the kit feels real.

## Make it yours

Use the actual bundle, accessories, quantities, and customer task. Change the number of products, arrangement, and setting for the offer. Do not imply necessity, compatibility, or a combined result unless the supplied information supports it.

## Optional prompt seed

```text
Arrange the supplied [BUNDLE OR KIT] as a clear [ROUTINE, PREPARATION, OR COMPLEMENTARY SET]. Give each item a readable place on [SURFACE], use consistent light and true relative scale, and add only the usage cues that help the buyer understand how the pieces relate.
```
