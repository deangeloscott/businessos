# At-a-glance comparison

Use this when someone needs to choose between options and the decision can be made clearer by seeing the same criteria side by side.

## The idea

Start with the actual decision question, then compare the options on the few dimensions that matter most to that decision. Keep the rows parallel, make tradeoffs visible, and let the recommendation follow from the stated criteria. A comparison can be between a product and a generic alternative, two service approaches, or two possible plans; it does not need to name a competitor.

## Borrowable shape

**Decision question → options → three to five meaningful criteria → differences and tradeoffs → supported recommendation or next step.**

Give each option the same visual space and language. Emphasize a preferred option only when the distinction is supported by the supplied facts or is clearly framed as an illustrative concept. Use a short note for an important limitation rather than hiding it in fine print.

## Tiny illustrative example

**Which setup is easier for a small team to operate?**

| | In-house setup | Managed setup |
|---|---|---|
| Initial effort | More configuration | Less setup work |
| Control | More direct control | More provider dependence |
| Ongoing work | Team maintains it | Provider handles more of it |

The card ends with: **Choose based on where the team wants to spend its time.** This is a fictional illustration of the structure, not a claim about either option.

## Adapt

Use criteria the audience actually uses: fit, durability, total cost, speed, control, support, compatibility, or another decision variable. Use measured values when they are available; otherwise describe the difference without inventing a score. For a product comparison, show the real product clearly and keep a generic alternative generic unless a named comparison is supported and appropriate.
