# ViralTrac AURA Branding

## Official public name

**ViralTrac AURA**

AURA stands for **Agentic Understanding and Reinforcement Architecture**.

## Descriptor

ViralTrac AURA is an **AI-native BusinessOS**: a portable agentic business operating architecture for understanding a business, coordinating governed work, measuring outcomes, retaining Learning, and improving future operating processes.

“BusinessOS” remains a useful descriptor/category and may continue to appear in technical documentation, internal namespaces, compatibility identifiers, and explanatory copy. It is no longer the primary public product name.

## Naming rules

- On first external/public mention, prefer: **ViralTrac AURA (Agentic Understanding and Reinforcement Architecture), an AI-native BusinessOS**.
- After first mention, use **ViralTrac AURA**. Use bare **AURA** only when the ViralTrac context is unmistakable.
- Do not present the current product publicly as “ViralTrac's BusinessOS” or “ViralTrac BusinessOS” except when describing historical versions, legacy compatibility, or the license history.
- Preserve stable technical compatibility identifiers such as the repository name `businessos`, `BUSINESSOS_*` environment variables, existing contract IDs, object extensions, and established filesystem conventions unless a dedicated compatibility migration explicitly changes them.
- Component distributions use the AURA family name, for example **ViralTrac AURA — Content** and **ViralTrac AURA — SEO/AEO**.
- “ViralTrac” remains the first-party companion/product ecosystem brand and should not be implied to be mandatory for AURA operation.

## Brand boundary

The AURA name does not change portability, provider neutrality, model/harness independence, local-first operation, or the separation between public AURA source and proprietary ViralTrac hosted software. Naming must not imply that AURA requires a ViralTrac account, hosted control plane, proprietary runtime, Git provider, or second-brain application.

## Market-name caution

“AURA” is a widely used name across software and AI. Public-facing material should therefore consistently use the composite **ViralTrac AURA** mark rather than relying on “AURA” alone. This branding policy is not a legal trademark clearance; formal clearance should be completed before broad commercial trademark use.
