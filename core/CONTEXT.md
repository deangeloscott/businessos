# Business OS Core

Core owns the grammar of collaboration: canonical business context, common object/lifecycle contracts, lineage, opportunity/action control, measurement/evaluation, learning governance, playbook-evolution and business-scoped process-extension governance, routing/context planning, external-ecosystem discovery/provenance/triangulation mechanics, optional Innovation Exchange package/privacy/community-evidence mechanics, configurable product-vs-organization workspace resolution, human knowledge-view governance, provider-neutral capability resolution, portable-first/local-state rules, provider preference governance, and business isolation. Core does not decide domain meaning for customers, competitors, industry, organic discovery, content, persuasion, or customer progression; installed domain owners interpret external/community evidence and choose domain-specific tests/actions. Canonical BusinessOS source remains protected during ordinary business work; local ProcessExtensions can adapt behavior without turning a business-specific success into a universal rule or creating a hard dependency on an exchange service, Git provider, hosted state service, Obsidian, or another human-interface tool. Canonical JSON state remains authoritative even when Core generates human-readable Markdown views from it.
