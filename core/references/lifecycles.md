# Canonical Lifecycles

## Insight
candidate → supported → active → stale/superseded/contradicted/archived

## Opportunity
candidate → investigating → qualified → prioritized → committed → active → evaluating → closed
Side: blocked, rejected, superseded, reopened.

## ChangeEvent
planned → applying → applied → verifying → verified → closed
Side: partially_applied, failed, rolled_back.

## Learning maturity
hypothesis → experimental → emerging → validated → standard

## Learning status
active, contradicted, deprecated, superseded

## AttentionItem
open → acknowledged → resolved → archived
Side: superseded; resolved may reopen when the same semantic condition genuinely recurs.

## PlatformChange
current → superseded → archived
Unchanged re-verification updates the current version rather than creating another object.
