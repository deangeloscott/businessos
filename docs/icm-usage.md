# ICM-Style Usage

The Business OS is inspired by In-Context Memory / filesystem-oriented agent workflow principles: readable stage/job contracts, explicit inputs/process/outputs, durable intermediate state, minimal relevant context, human inspectability/editability, and deterministic utilities for mechanical work.

The architecture extends that pattern for a network of specialized operating systems. Instead of forcing one sequential folder pipeline, canonical objects and events allow Customer, Competitor, Industry, SEO/AEO, Content, Marketing, and Customer Optimization systems to share intelligence without duplicating state. A fresh capable model/provider can use the same contracts; quality may differ by model capability, but the business process does not depend on a specific model vendor.
