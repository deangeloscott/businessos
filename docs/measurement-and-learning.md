# Measurement & Learning

`MetricDefinition` says what a metric means. `MetricObservation` says what was measured. `VerificationRecord` says whether an intended change happened. `OutcomeEvaluation` says what happened afterward and how confidently the intervention contributed. These are intentionally separate.

Outcome Evaluation records baseline, evaluation window, expected/observed effects, attribution method, confounders, guardrails, conclusion, and causal confidence. Shared outcomes must not be counted once per contributing system.

Learning begins at the narrowest justified scope: domain → business → system. Maturity progresses hypothesis → experimental → emerging → validated → standard; status can become contradicted/deprecated/superseded. System Learning requires stronger replicated evidence and explicit cross-business eligibility.
