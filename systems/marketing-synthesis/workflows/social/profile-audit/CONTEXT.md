# Social Profile Audit & Optimization

## Purpose
Evaluate and improve a social profile so qualified visitors can quickly understand who the business helps, why it matters, why to trust it, and what to do next.

## Business Outcome
Improve qualified progression from profile visits without treating the profile as generic branding decoration or splitting diagnosis from the obvious correction work.

## Run When
Use when a social profile is a meaningful acquisition/conversion surface, its message or offer has changed, or current performance/evidence suggests the profile may be limiting qualified progression.

## Process
1. Resolve the profile’s platform, primary AudienceSegment, Brand, Offer, acquisition role, desired action, current Assets, relevant entry content, and current platform constraints.
2. Audit identity recognition, display name/handle clarity, bio/value proposition, proof, CTA, destination link, pinned/featured content, profile imagery, and message continuity from common entry content.
3. Identify ambiguity about audience, outcome, differentiation, credibility, or next step. Separate profile persuasion problems from downstream landing-page, offer, or journey friction.
4. When improvement is justified, define the simplest coherent audience/value/CTA path; use variants only when the account genuinely serves incompatible audiences that cannot be expressed clearly together.
5. Draft the useful profile changes directly: display-name/bio/value proposition/CTA/link language, proof selection, pinned/featured-content recommendations, and profile-image/banner/cover requirements as relevant. Use Content operating knowledge or another suitable method for substantial creative production rather than duplicating it here.
6. Verify customer-facing claims and proof against established business truth; validate links, tracking, destination-message continuity, accessibility, and current platform field/character/link constraints using the best available current source or tool when they matter.
7. If the user’s request and real permissions allow implementation, apply the changes with the active platform/tool and verify the live result. Otherwise return an exact usable draft or implementation specification. Create a WorkRequest only when a genuine durable handoff to another owner must survive the current session.
8. Capture before/after evidence and evaluate profile-to-destination or intended-action behavior over an appropriate window when measurement is useful and actually available; do not fabricate uplift or require measurement ceremony for trivial edits.

## Proportionate Scope
Audit and change only the profile elements that can materially affect the requested outcome. Broaden into pinned content, creative, destination, or cross-platform consistency when evidence suggests those elements are part of the same decision path.

## Verification
- Recommendations and changes trace to the actual profile, business context, platform behavior, and relevant evidence.
- Customer-facing claims remain within established business truth.
- Baseline/performance values are recorded only when actually observed.
- AURA does not substitute an internal action, approval, or execution object for the real implementation tool or owner.
