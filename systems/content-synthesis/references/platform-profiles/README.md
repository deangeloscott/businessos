# Platform Profiles

Platform behavior changes. Do not hard-code unstable platform rules into production contracts. `PlatformProfile` records current, sourced behavior and constraints for a platform/surface and may include business-specific Content Learning.

Use a profile when platform mechanics materially affect format, duration, layout, interaction, or distribution. Refresh it when stale, contradicted, or missing for a consequential production decision. A profile is evidence, not a promise that an algorithm will behave consistently.
