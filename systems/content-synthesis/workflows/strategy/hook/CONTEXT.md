# Content Hook Design

## Purpose
Create an opening that earns attention by making the content’s real value, tension, novelty, consequence, or curiosity immediately clear.

## Business Outcome
Increase qualified attention without misleading clickbait or sacrificing message integrity.

## Run When
Run when the selected format needs an explicit opening hook, headline, first frame, or first line.

## Process
1. [AI] Identify the strongest true reason this audience should care now: outcome, problem, tension, surprise, demonstration, specificity, consequence, or unresolved question.
2. [AI] Generate several materially different hook mechanisms rather than cosmetic rewrites.
3. [HYBRID] Reject hooks that promise something the asset does not deliver, manufacture urgency, remove necessary qualifiers, or target the wrong audience.
4. [AI] Match hook speed/depth to platform consumption behavior and the audience’s awareness.
5. [AI] Prefer showing/demonstrating evidence early when the format and subject make that more credible than assertion.
6. [DETERMINISTIC] Select/test the strongest candidates using known Content Learnings or experiment plan where appropriate.
7. [AI] Carry the chosen hook into the opening structure so the payoff occurs quickly and coherently.
