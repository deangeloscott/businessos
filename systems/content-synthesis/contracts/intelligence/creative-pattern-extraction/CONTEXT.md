# Creative Pattern Extraction

## Purpose
Extract the reusable mechanism behind strong content so the business can learn from it without imitating the source's protected expression, identity, or exact creative.

## Business Outcome
Turn examples into reusable creative reasoning—hooks, structures, demonstrations, proof patterns, pacing, or interaction mechanics—that can generate original content across topics.

## Run When
Run when several content examples suggest a repeatable creative mechanism or when an operator wants to understand why a particular content pattern may work.

## Process
1. [DETERMINISTIC] Assemble the source examples and comparable weak/ordinary examples when available; preserve platform, creator, audience, timing, and source context.
2. [AI] Decompose each example into hook, tension/question, information sequence, emotional mechanism, proof/demo, visual grammar, pacing, payoff, CTA, and interaction design.
3. [AI] Identify the smallest structural/mechanistic elements shared by the stronger examples and separate them from topic, wording, visual assets, creator persona, or brand-specific expression.
4. [AI] Generate alternative explanations for observed performance and note what is unsupported because distribution, audience size, paid reach, or external events are unknown.
5. [HYBRID] Test whether the pattern remains meaningful across several examples/platform contexts and whether it conflicts with Brand, audience, or factual constraints.
6. [AI] Write the pattern as an original reusable mechanism with applicability conditions, non-applicability, examples of use, and confidence—never as “copy this creator/post.”
7. [HYBRID] Publish a Content Insight first; promote to experimental/emerging Content Learning only when repeated business/external evidence justifies reuse.
