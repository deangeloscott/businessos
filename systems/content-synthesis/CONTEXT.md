# Content Synthesis

## Purpose
Turn insights and source material into high-quality communication native to audience, objective, platform, medium, and consumption context.

## Canonical Scope
Idea/angle/format/platform selection, narrative, scripts, text, images, carousels, presentations, audio/video/animation, editorial QA, native adaptation, content learning.

## Explicit Non-Scope
Does not own customer/competitor truth, organic diagnosis, commercial persuasion strategy, offers, or journey optimization.

## Shared behavior
Use Core canonical objects and policies. Consume current canonical intelligence before repeating broad research. Publish reusable Observations/Insights. Create Opportunities only for independent interventions inside this domain; delegate production through WorkRequests. Persist only domain-specific state under the active business instance.
