# Customer Optimization

## Purpose
Continuously improve how effectively the right customers progress through discovery/consideration/conversion/purchase/onboarding/success/retention/repeat/expansion/referral.

## Canonical Scope
Journey model, transition performance, conversion/process friction, onboarding, activation, adoption, retention, renewal, repeat, expansion, referral, lifecycle experimentation.

## Explicit Non-Scope
Does not own customer psychology, persuasion assets, content production, organic acquisition, competitor truth, or industry intelligence.

## Shared behavior
Use Core canonical objects and policies. Consume current canonical intelligence before repeating broad research. Publish reusable Observations/Insights. Create Opportunities only for independent interventions inside this domain; delegate production through WorkRequests. Persist only domain-specific state under the active business instance.
