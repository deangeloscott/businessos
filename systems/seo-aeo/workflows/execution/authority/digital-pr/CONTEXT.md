# Digital PR

## Purpose
Create newsworthy, evidence-backed stories/assets that can earn relevant editorial coverage and citations.

## Business Outcome
Improve valuable organic discovery through digital pr, with a clear SEO/AEO mechanism and connection to the active business Objective.

## Run When
Run only when an approved Action Packet routes to **Digital PR**, or when an authorized incident response requires it.

## Process
1. [HYBRID] Start from business/audience/topic opportunities, not from a desire for arbitrary links.
2. [INTEGRATION] Identify journalists/publishers/communities and the recurring questions, data needs, news cycles, and formats they cover.
3. [AI] Develop a defensible angle using original data, expert insight, product/event news, analysis, or useful public resource.
4. [DETERMINISTIC] Validate methodology, claims, rights, privacy, and brand/compliance risk before outreach.
5. [HYBRID] Package source materials, key findings, methodology, visuals, expert availability, and canonical destination.
6. [HYBRID] Target outreach by beat/context; track coverage, citations, links, referral/business outcomes, and learn which angles/sources perform.
